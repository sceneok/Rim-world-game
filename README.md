# 림 서바이벌 - 개척지 생존기

림월드 / 서바이벌 애프터매스 스타일의 콜로니 생존 시뮬레이션 게임입니다.
그래픽은 듀오링고 느낌의 밝고 둥근 스타일(직접 그린 캐릭터·동물·건물, 입체 버튼 UI)입니다.
설치 없이 브라우저에서 `index.html`을 열면 바로 실행됩니다. (HTML5 Canvas + 순수 JavaScript)

## 게임 개요
- 우주선 추락에서 살아남은 **정착민 3명**으로 시작합니다.
- 방랑자 합류, 탈출 포드 추락(구조 후 합류), 피난민 요청 등 **이벤트로 인원이 늘어납니다.**
- 3일차부터 **약탈자 습격**이 시작되며 날이 갈수록 규모와 무장이 강해집니다. 광폭화 동물도 습격합니다.
- 모든 정착민이 사망하면 게임 오버입니다.

## 생존 신호
| 신호 | 설명 |
|---|---|
| 체력 | 전투/굶주림/저체온증으로 감소. 15 미만이면 쓰러짐 → 동료가 구조·치료·급식 |
| 허기 | 식사(🍲)나 날음식을 먹어야 함. 0이 되면 굶주림 피해 |
| 수면 | 밤에 침대에서 수면. 바닥/야외 수면은 기분 하락. 0이면 탈진 |
| 체온 | 쾌적 온도(기본 4~33°C)를 벗어나면 저체온증/열사병 → 피해. 파카·난방된 방 필요 |
| 기분 | 식사·수면·동료의 죽음 등에 영향. 너무 낮으면 정신이상으로 방황 |

## 주요 시스템
- **자원 수집**: 벌목(목재), 채굴(석재·강철), 채집(산딸기·약초), 사냥(고기·가죽), 재배(쌀)
- **건설**: 나무/석재 벽, 문, 침대, 식탁, 모닥불, 작업대, 난방기, 냉각기, 모래주머니, 방어 터렛, 가시 함정
- **제작**: 모닥불(식사), 작업대(몽둥이·창·활·파카·가죽 갑옷·약품) — 'N개 만들기 / N개 유지 / 반복' 작업 지시
- **방(실내) 온도**: 벽과 문으로 완전히 둘러싼 공간은 실내로 인식되어 난방/냉각 효과를 받습니다
- **계절과 날씨**: 봄·여름·가을·겨울(각 6일), 한파·폭염 이벤트
- **작업 배정**: 정착민별 작업 종류 on/off (왼쪽이 우선)
- **전투**: 소집(Draft) 후 우클릭으로 이동/공격, 엄폐(모래주머니), 터렛, 함정
- **상인**: 물물교환 / **저장·불러오기**: 브라우저 localStorage (하루마다 자동 저장)

## 조작
| 입력 | 동작 |
|---|---|
| WASD / 방향키 / 좌클릭 드래그 | 화면 이동 |
| 마우스 휠 | 확대/축소 |
| 좌클릭 | 선택 (도구 선택 시 드래그로 지정/건설) |
| 우클릭 | 도구 취소 / 소집 상태에서 이동·공격 |
| Space / 1·2·3 | 일시정지 / 속도 |
| F / R | 선택 정착민 소집 / 전원 소집 |
| Tab | 다음 정착민 |
| T | 온도 오버레이 |
| Esc | 선택·도구 해제 |

## 시작 팁
1. **벌목**을 넓게 지정하고, 나무 벽 + 문으로 작은 방을 만드세요.
2. 방 안에 **침대**와 **모닥불**을 두면 따뜻하게 잘 수 있습니다.
3. **재배 구역**을 만들고, 원거리 무기를 가진 정착민으로 **사냥**하세요.
4. 가죽으로 **파카**를 만들어 겨울(19일차~)에 대비하세요.
5. 강철을 채굴해 **터렛**과 **난방기**를 건설하세요.

## 파일 구조
```
index.html      화면 레이아웃
style.css       스타일
js/data.js      게임 데이터(아이템·건물·레시피·동물·특성)
js/world.js     맵 생성, 방/온도 계산, 아이템·비축
js/path.js      A* 길찾기

js/events.js    스토리텔러(습격·합류·날씨·상인 등 이벤트)
js/render.js    캔버스 렌더링
js/ui.js        UI 패널, 입력 처리
js/main.js      게임 루프, 새 게임, 저장/불러오기
```

# 다이노 아일랜드 (3D)

`dino-island/index.html` — 공룡이 사는 섬에서 살아남는 3D 3인칭 생존 게임입니다. Three.js(CDN)를 쓰며, 파일 하나를 브라우저로 열면 실행됩니다.

- **그래픽**: 밝은 카툰풍 로우폴리. 지형·나무·공룡·캐릭터를 모두 코드로 모델링
- **채집**: 나무(목재), 바위(돌), 덤불(산딸기·섬유)
- **공룡**: 파카룡(겁 많음), 뿔방패룡·목긴룡(맞으면 반격), 날쌘발톱(선공, 밤에 늘어남)
- **제작**: 돌도끼, 돌곡괭이, 돌창, 가죽 옷, 붕대, 구운 고기
- **건설**: 모닥불(요리·회복·빛), 나무 울타리(공룡 차단), 움막(잠자기·부활 지점)
- **생존**: 체력·포만감·기력, 낮/밤 순환, 목표 가이드, 미니맵, 자동 저장(localStorage)
- **시점·조작**: 고정 쿼터뷰(휠 줌). 땅 클릭으로 이동, 나무·바위·공룡 클릭 시 다가가 자동 채집·공격. WASD·E·Shift·Space·1~4·C 키, 폰은 탭·조이스틱·버튼
- **재료 패널**: 왼쪽에 모든 재료 개수를 항상 표시, 늘거나 줄면 깜빡임
